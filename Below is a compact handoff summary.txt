## Project Summary — Family Photos App

### Objective

Stabilize and deploy a self-hosted family photo gallery so that **thumbnails and full-size images load correctly in production**, matching localhost behavior after migrating to a new Windows 11 machine.

---

### Platform / Stack

* **Backend:** Node.js (ESM) + Express, SQLite, Sharp
* **Frontend:** React + Vite
* **Auth:** Firebase Authentication (token-based, no cookies)
* **Hosting:**

  * Frontend: Firebase Hosting
  * Backend: Local Node server exposed via **Cloudflare Tunnel**
* **OS:** Windows 11
* **Photos Storage:** External drive (`G:\Photos`)

### Potential Pitfalls / Gotchas

* **API shape mismatches** (envelope vs array) can silently break UI
* **Relative `/api/*` paths** work locally but fail in production without a base URL
* **CORS rules**: `credentials: include` cannot be used with `Access-Control-Allow-Origin: *`
* **React Hooks order violations** may only fail in production builds
* **Firebase Hosting paths** depend on deploy working directory
* **Cloudflare Tunnel must be running** independently of the backend
* Local dev proxies can mask real production issues
